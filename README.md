# Executive Command Center & Sales Intelligence Suite

A production-grade, enterprise-level retail analytics dashboard built to bridge the gap between basic data visualization and corporate Business Intelligence standards. Designed with an institutional dark-mode aesthetic to showcase advanced financial tracking and pricing elasticity modeling.

---

## Tech Stack & Architecture
* **Language:** Python
* **Web Framework:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Plotly Express (Interactive Vector Graphics)
* **Design Pattern:** Vercel/Linear-inspired minimalist UI with multi-tab architecture

---

## Core Features & Analytical Modules

1. **Executive Overview:** 
   * Real-time KPI summary cards tracking Gross Revenue, Gross Profit, Average Order Value (AOV), and Net Profit Margins.
   * High-level operational trend tracking and regional distribution analysis.

2. **Product & Discount Intelligence:**
   * Commercial pricing elasticity modeling.
   * Dedicated discount sensitivity analysis evaluating how discounting strategies impact volume and net revenue output.

3. **Granular Data Ledger:**
   * Searchable, filterable transactional database view for deep-dive exploratory data analysis.

4. **Dynamic Parameter Filters:**
   * Sidebar controls supporting real-time temporal slicing, regional filtering, and category selection.
